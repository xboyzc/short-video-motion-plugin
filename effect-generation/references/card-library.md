# Overlay Studio 固定卡片库

只允许下列 5 个 `kind`。名称必须逐字匹配，不得使用显示名称、缩写或别名。

## 选择优先级

当同一字幕区间可能匹配多种卡片时，按以下顺序选择：

1. `metric-focus`
2. `compare-split`
3. `quote-lockup`
4. `signal-card`
5. `kinetic-text`

不要为了丰富形式而降低语义匹配度。

## 1. metric-focus

用途：突出字幕中明确出现的阿拉伯数字、百分比、倍数、金额、时长或计数。

必须满足：

- `value` 与 `suffix` 可以从字幕原文直接拆出。
- 不把模糊数量词改造成数字。
- `detail` 只说明这个数字代表什么。

固定视觉预设：

```json
{"x":7.3,"y":30.0,"w":22.5,"fontSize":124}
```

## 2. compare-split

用途：字幕明确表达两种方案、前后状态、传统与新方式、A 与 B 的差异。

必须满足：

- 左右双方都能从 1–3 条连续字幕中确定。
- 不把普通并列句强行解释成对比。
- 左右数值或短语保持原意。

固定视觉预设：

```json
{"x":4.5,"y":35.0,"w":91.0,"fontSize":38}
```

该卡片自身包含左右两翼，中央人物区域保持安全；不得与其他卡片同时出现。

## 3. quote-lockup

用途：可脱离上下文独立成立的结论、金句、原则或判断。

必须满足：

- `quote` 使用字幕原句，只允许删除口头填充词和修正明显断句。
- 不改写事实、因果或态度强度。
- 字幕没有来源时 `source` 必须为空字符串。

固定视觉预设：

```json
{"x":5.8,"y":22.0,"w":27.0,"fontSize":32}
```

## 4. signal-card

用途：把 2–3 条连续字幕整理为逐句出现的信息摘要。

必须满足：

- 至少有 2 个有效信息层级。
- 每行是短句，不复制整段长字幕。
- `line3` 和 `footer` 可以为空字符串。

固定视觉预设二选一：

```json
{"x":4.6,"y":23.5,"w":27.2,"fontSize":31}
```

```json
{"x":68.2,"y":23.5,"w":27.2,"fontSize":31}
```

左右预设交替使用时仍需避开同区间其他卡片。

## 5. kinetic-text

用途：强调 1–3 个短促、有节奏的关键词或短句。

必须满足：

- 每行不超过 12 个字符。
- 不承载长解释、完整段落或复杂数据。
- `line2`、`line3` 可以为空字符串。

固定视觉预设二选一：

```json
{"x":4.5,"y":19.0,"w":27.0,"fontSize":54}
```

```json
{"x":68.5,"y":19.0,"w":27.0,"fontSize":54}
```

## 禁用类型

- `picture-in-picture`：需要视频媒体，不可仅由 SRT 推导。
- `image-feature`：需要图片媒体，不可仅由 SRT 推导。
- 其他任意名称：不存在于当前允许库。
